# AI-Integrated RAG Model for Profit Maximisation in Healthcare

An AI-powered **Retrieval-Augmented Generation (RAG)** system designed to support **CPT (Current Procedural Terminology) coding and package optimisation** for *Theratap*, a mental healthcare platform.

The system combines **OpenAI APIs, vector embeddings, semantic retrieval, and prompt engineering** to retrieve relevant healthcare and coding information and generate context-aware CPT coding recommendations. The objective is to improve coding efficiency while identifying **revenue and profitability optimisation opportunities** for healthcare services.

## Key Features

* **RAG Architecture:** Retrieves relevant information from a knowledge base before generating responses.
* **Vector Embeddings:** Converts healthcare and CPT-related information into vector representations for semantic search.
* **LLM Integration:** Uses OpenAI APIs to generate context-aware coding recommendations.
* **Prompt Engineering:** Designed structured prompts to improve the accuracy, consistency, and relevance of generated CPT coding packages.
* **CPT Package Optimisation:** Generates suitable combinations of CPT codes based on retrieved clinical/service information.
* **Profit Optimisation:** Supports analysis of coding packages with the objective of maximising potential revenue and profitability.
